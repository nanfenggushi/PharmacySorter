开发这种**软硬件结合**的系统，最忌讳的顺序就是“从头开始画界面”。如果先把所有漂亮界面画完，最后发现连不上机械臂，那之前的代码就全白写了。

业内标准的开发节奏是“自底向上，风险优先”。我建议你将整个开发过程拆分为以下 **5 个阶段**，按这个顺序写代码最顺畅：

### 第一阶段：打地基（环境与数据库）

这是最没有技术难度但必须先做的一步，为整个系统建立骨架。

1. **建库建表**：打开 SQL Server，直接运行我之前发你的完整 SQL 脚本，把 5 张表建好，并执行那一批 `INSERT` 初始语句。
2. **建项目结构**：打开 Visual Studio，创建名为 `MediArm` 的解决方案，并按之前讨论的，建好 `UI` (界面)、`Core` (业务逻辑)、`Hardware` (硬件通信)、`Models` (实体类) 这几个目录或子项目。
3. **连接数据库**：写一个简单的 `DbHelper` 类，用 ADO.NET（或 Dapper）跑通最简单的数据库连接测试。

### 第二阶段：攻克最高风险（机械臂通信通信层）

**不要急着画复杂的业务界面！** 先弄一个最丑的测试窗口，把软硬件打通。这是整个项目的核心命脉。

1. **写硬件类**：在 `Hardware` 层封装串口服务，实现打开串口、关闭串口和发送字符串。`$DGT:13-17,1!` 不能原样发送，要先按控制器 INI 展开成 G0013 至 G0017 的 `#000P...T...!` 舵机帧。
2. **做个粗糙的测试界面**：随便新建一个临时窗体，放一个下拉框选 COM 口，放一个按钮写着“测试左抓”。
3. **联调验证**：点击按钮，让代码发送左侧动作组展开后的舵机帧。如果机械臂乖乖向左动了，说明你的整个技术路线 100% 可行！这个阶段跑通了，后面全是纯软件逻辑的体力活。

### 第三阶段：粮草先行（基础数据管理页）

机械臂能动了，接下来要让系统知道“去哪抓、抓什么”。主流程必须依赖这些基础数据才能运转。

1. **开发 `DrugDictionaryForm` (药品字典)**：
   - 写出药品的增删改查代码（CRUD）。
   - 新增和编辑时用下拉框把药品绑定到“左侧药位”或“右侧药位”，也可以保持未绑定。
   - 目标：让数据库的 `Drug` 表里有真实的药，并把 `StationId` 填上。
2. **开发 `DrugStationMappingForm` (工位指令配置)**：
   - 维护三个固定工位的抓取指令、放置指令和动作延时。
   - 目标：配药时按药品已保存的工位读取对应宏指令。本页不再重复维护药品绑定。


### 第四阶段：系统大脑（处方流转与自动抓取）

这是代码量最大、最有含金量的部分，开始把数据和硬件串联起来。

1. **开发 `PrescriptionCenterForm` (处方录入中心)**：
   - 实现左侧的处方明细录入，点击保存后，把数据写入 `Prescription` 和 `PrescriptionItem` 表。
2. **开发 `DashboardForm` (配药监控看板) 的核心循环**：
   - 写一个后台任务（可以使用 `Task`，避免界面卡死）。
   - **核心逻辑**：串口连接成功后自动启动一次 → 优先继续“配药中”或“部分异常”处方 → 否则读取待配队列 → 展开工位动作组并下发舵机帧 → 在后台按 `EstTimeMs` 等待 → 更新 `GrabCount`。当前处方完成后自动读取下一张，没有处方时等待新处方。急停后保留进度，按钮恢复后可手动再次启动，从剩余次数继续。串口未连接时不自动启动。

### 第五阶段：安全闭环与收尾（核对纠错与日志）

现在系统已经能自动干活了，最后一步是加上防呆机制和事后审计。

1. **开发 `QuantityVerificationDialog` (数量核对弹窗)**：
   - 在第四阶段的“核心循环”中加入拦截点。抓完一种药，弹出这个 Form，调用 `ShowDialog()` 阻塞主线程。
   - 编写**漏抓补缺**（自动再次调用抓取逻辑）和**多抓剔除**的判断代码。
2. **开发 `SystemAuditLogForm` (系统操作日志审计)**：
   - 在每个关键节点（下发指令、弹出核对、出现异常、登录和账号变更）加上写日志的代码 `Insert into AppLog`。
   - 把日志查询和导出 Excel 的界面做完。
3. **开发登录与 `UserAdminForm` (账号与角色管理)**：
   - 程序入口先显示登录窗口。密码使用 PBKDF2 哈希校验，不保存明文。
   - 主界面按管理员、药师、操作员显示不同菜单。
   - 管理员可以新增账号、调整角色和启停账号。新增与保存分开：新增不受表格选中行影响，保存不能修改登录账号。
4. **全局急停**：把左下角的红色急停大按钮逻辑写上。点击后先打断正在等待的动作，再下发 G0002 拼好的舵机指令：`#000P1500T1000!#001P1500T1000!#002P2300T1000!#003P1000T1000!#004P1500T1000!#005P1500T1000!`。不要只发底座一帧，也不要发 `$DGT`。

**给你的行动建议：**

今天打开电脑后，先搞定**第一阶段（建库和建类）**，然后马上直奔**第二阶段**去写个临时按钮测试机械臂。只要那个按钮点下去机械臂动了，你的成就感会瞬间拉满，后面的代码写起来也就一气呵成了。
